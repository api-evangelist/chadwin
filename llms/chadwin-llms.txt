# Chadwin

Chadwin provides SEC filing data for apps, websites, and agents through an API, Node.js SDK, and MCP server.

Current documentation covers normalized annual financial statements and metrics from Form 10-K filings; company reports on Forms 10-K, 10-Q, 20-F, and 40-F; insider ownership and transaction filings on Forms 3, 4, and 5; Form 144 proposed-sale notices; and Form 13F institutional holdings. Use the API reference or OpenAPI document for exact paths, parameters, and response schemas.
